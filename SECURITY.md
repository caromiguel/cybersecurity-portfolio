# Security and Responsible Use

This repository contains educational cybersecurity material produced in authorized environments.

## Reporting a Repository Security Concern

Do not open a public issue containing credentials, personal information, active tokens, vulnerable live targets, or other sensitive data. Contact the repository owner privately at miguel.caro@live.com.

## Content Standards

Portfolio material must not include:

- Credentials, private keys, access tokens, or session identifiers
- Real customer, employer, or government system details
- Personal data belonging to lab participants
- Unredacted public IP addresses or internal host inventories
- Malware samples or unnecessarily weaponized exploit code
- Protected certification exam content

All examples should use isolated labs, CTF environments, or systems with explicit authorization.
