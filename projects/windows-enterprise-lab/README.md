# Windows Enterprise Lab

## Overview

A virtual enterprise environment used to practice Windows infrastructure deployment, identity administration, endpoint onboarding, automation, and validation.

## Lab Components

- Windows Server and Windows 11 virtual machines
- Hyper-V networking
- Active Directory Domain Services
- Domain Name System configuration
- Organizational units, users, groups, and access controls
- Domain-joined endpoints
- PowerShell administration and Pester validation

## Core Tasks

1. Plan and assign addressing for the lab network.
2. Rename systems and network adapters consistently.
3. Install AD DS and promote the server to a domain controller.
4. Configure DNS and validate name resolution.
5. Install and join a Windows 11 endpoint to the domain.
6. Configure services and administrative settings.
7. Verify the build with PowerShell and automated tests.
8. Document troubleshooting decisions and final state.

## Skills Demonstrated

Windows Server administration, identity and access management, virtualization, PowerShell, configuration validation, troubleshooting, and technical documentation.

> Screenshots and configuration samples are sanitized before publication; passwords, real domains, and sensitive infrastructure details are excluded.
