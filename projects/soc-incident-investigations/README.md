# SOC Incident Investigations

## Overview

A collection of authorized SOC lab investigations covering web attacks, brute-force activity, suspicious authentication, reconnaissance, and sensitive-data exposure. The work emphasizes defensible conclusions based on evidence rather than alert titles alone.

## Investigation Workflow

1. Validate the alert and establish scope.
2. Correlate events across host, network, identity, and application telemetry.
3. Build a timeline and identify relevant indicators.
4. Map observed behavior to MITRE ATT&CK.
5. Classify severity using impact and confidence.
6. Recommend containment, eradication, recovery, and monitoring actions.
7. Record lessons learned and detection improvements.

## Tools and Frameworks

- Wazuh, Splunk, and Suricata
- Network and application logs
- MITRE ATT&CK
- Incident severity and escalation procedures
- IOC analysis and evidence preservation

## Representative Scenarios

- Authentication brute-force investigation
- Web application attack triage
- IDS alert validation
- API abuse and sensitive-data exposure
- Network scanning and insecure-service detection

## Skills Demonstrated

Alert triage, event correlation, timeline reconstruction, severity assessment, MITRE mapping, remediation planning, and concise technical reporting.

> Evidence is sanitized. Usernames, IP addresses, tokens, proprietary identifiers, and exploit-enabling details are removed or replaced.
