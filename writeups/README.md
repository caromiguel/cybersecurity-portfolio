# Security Writeups

This section will contain sanitized writeups from authorized labs, CTFs, and defensive investigations.

## Writeup Standard

Each entry should include:

- Scenario and learning objective
- Scope and authorization statement
- Environment and tools
- Evidence collected
- Analysis and reasoning
- MITRE ATT&CK or OWASP mapping when relevant
- Defensive recommendations
- Lessons learned
- Sanitization note

Writeups focus on analysis, detection, and remediation. They do not disclose credentials, real organizational data, live targets, or unnecessarily weaponized procedures.
