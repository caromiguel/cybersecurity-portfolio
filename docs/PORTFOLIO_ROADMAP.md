# Portfolio Roadmap

## Priority 1 — Publish Evidence

- Add one sanitized PDF or Markdown case study to each featured project.
- Include screenshots with captions explaining what the evidence proves.
- Replace all real identifiers with clearly labeled lab values.
- Add a short results section with measurable outcomes where available.

## Priority 2 — Improve Recruiter Usability

- Keep each project summary readable in under two minutes.
- Put the strongest three projects at the top of the main README.
- State personal responsibilities clearly for group assignments.
- Link skills to concrete evidence rather than listing tools alone.
- Add a downloadable résumé only after checking it for personal and sensitive information.

## Priority 3 — Show Technical Depth

- Add sanitized Splunk SPL and PowerShell examples.
- Add a network diagram for the segmented home lab.
- Include detection logic, validation steps, and false-positive analysis.
- Add before-and-after remediation evidence.
- Document testing limitations and residual risk.

## Publication Checklist

- [ ] Confirm the system was authorized for testing.
- [ ] Remove credentials, tokens, keys, and session data.
- [ ] Replace public IPs, hostnames, usernames, case IDs, and client names.
- [ ] Remove employer/customer internal details and screenshots.
- [ ] Explain the objective, method, findings, remediation, and lesson learned.
- [ ] Check spelling, links, images, and Markdown rendering.
- [ ] Verify every certification and employment claim.
- [ ] Obtain permission before publishing group work.
